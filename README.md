# Strix Music

A stunning, highly-polished web application for showcasing AI-generated music by Strix Music. 

## Features
- **GSAP Animations**: Features fluid scramble text animations and smooth hover transitions.
- **Dynamic Glow Effects**: Tracks currently playing feature an animated glowing border using CSS conic gradients.
- **Interactive Backgrounds**: Dark mode aesthetic with glassmorphism effects and vinyl background previews that change on hover and stay visible while music is playing.
- **Built with**: React, Vite, TypeScript, and Tailwind CSS v4.

## Setup
```bash
npm install
npm run dev
```

## Deployment
Run `npm run build` to create a production-ready bundle.
